# 🏥 NGO Hub

### Healthcare Operations & Humanitarian Management Platform

NGO Hub is a full-stack digital platform designed to help NGOs manage their public services, emergency operations, medical equipment, volunteers, vehicles, reports, and internal workflows in one organized system.

The platform is being developed for the **Islamic Medical Association in Saida, Lebanon**.

---

## 🎯 Project Goal

NGO Hub helps NGOs move away from scattered files, manual processes, and disconnected tools.

It brings public communication and internal operations together in one platform that is:

- 🌍 Bilingual
- 📱 Responsive
- 🔐 Secure
- ♿ Accessible
- 📊 Data-driven
- 🤖 Ready for AI-assisted workflows

## 🚀 Run the Frontend Locally

Open a terminal in the `frontend` directory:

```bash
npm install
npm run dev
```

Open the English website:

```text
http://localhost:3000/en
```

Open the Arabic website:

```text
http://localhost:3000/ar
```

Run code checks:

```bash
npm run lint
npm run build
```
